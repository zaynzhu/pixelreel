# 产品行为约束

本文件记录跨页面、跨接口且容易在局部修改中被破坏的产品语义。具体字段和响应结构以代码
及测试为准，视觉样式以现有组件为准。

## 通用异步读取

- 列表、筛选、分页、详情、搜索、轮询和刷新均采用最新请求获胜。
- 视图条件变化时立即清除不属于新条件的记录、游标和错误。
- 旧请求的成功或失败不能写入新视图；页面卸载时使在途请求失效。
- 首次读取失败显示具体原因和重试入口，不能显示“没有数据”的健康空状态。
- 已有数据刷新失败时保留数据；分页失败保留列表和原游标，只重试失败的原请求。
- 操作失败与读取失败分开显示，不能让写入错误触发列表读取重试。

## 认证与设置

- 应用启动先读取 `/api/auth/status`；关闭认证时直接进入系统，开启时才要求 Token。
- 认证状态失败显示连接错误和重试，不能静默跳转登录页。
- 同一页面只允许一个登录请求；旧登录响应不能在退出或新请求后重新写入 Token。
- Settings 读取失败时保留已有表单，存在未保存改动时不得用重试覆盖。
- 保存期间锁定整个表单；敏感值保存成功后立即从前端状态清除，只保留已配置标记。
- 即时生效的主机平台配置不能清除请求中其他字段产生的重启提示。

## 资料库与详情

- `/api/library` 的列表、总数、来源计数、筛选和分页使用相同服务端条件。
- `category=media` 表示 `movie + tv_show`；cursor 是不透明字符串，调用方只能原样传回。
- 游戏卡片优先逐条读取平台档案，不跨平台汇总时长或成就。
- 统一详情按平台展示公开身份、首次导入、最后同步、时长和可信进度。
- 顶部遥测覆盖只统计含时长或成就/奖杯数据的平台档案，不显示跨平台合计。
- 路由切换后旧详情成功或错误不得覆盖当前记录；无效地址只提供返回入口。
- 状态、评分和短评是个人数据，重新匹配元数据或同步时不得覆盖。

## 首页与年度分析

- 首页“刷新统计”只读取 `/api/profile/summary`，不能伪装成同步。
- `pendingImports` 是三类记录中 `PENDING` 的总数，不包含 `IGNORED`。
- 同步入口沿用同步中心对临时账号和当前 Xbox Provider 的可用性判断，状态读取失败时不显示
  虚假的零待处理。
- 首页游戏平台摘要以平台档案汇总时长、覆盖率和可信已解锁数；无平台档案的遗留记录才回退
  旧字段。
- “继续”按有效进行中的游戏时长排序；“积压”按 WANT 入库时间排序；“回顾”选择高分完成
  且没有短评的记录，均为只读推导。
- 年度完成日期：豆瓣影视优先使用合法 `doubanDate`，否则使用 `updatedAt`；其他来源使用
  `updatedAt`。豆瓣日期按原始日历归属，时间戳按服务所在时区归属。
- 当前年度与上一年度同期比较；历史年度与上一完整年度比较。评分、短评、Top 榜和来源分布
  使用 `createdAt`。
- 本年游戏平台来源图按 `GamePlatformEntry` 计数，一条跨平台游戏可贡献多个平台档案。

## 时间线与 Showcase

- 时间线主列表、年份列表和分页绑定当前分类与年份；切换条件后不能混入旧记录。
- 时间线卡片按平台展示已知时长，零分钟仍显示；详情弹窗展示可信成就或奖杯。
- 详情弹窗在窄屏内自行滚动，标题和关闭入口不能被顶出视口。
- Showcase 首次读取失败显示原因和重试；已有内容刷新失败保留当前展厅。
- 海报轮换按批次采用最新请求获胜；失败时保留最后成功的海报并提供原地重试。
- 随机推荐的类别和状态筛选下推到 `/api/library/random`，不能先随机全库再在前端过滤。
- 390px 视口按阅读顺序纵向排列，不能产生页面级横向滚动。

## 同步中心与导入审核

- “需处理”数量基于当前 Xbox Provider、浏览器账号覆盖和来源真实可用性。
- 唯一缺口为默认账号时，填写本次临时账号应立即开放同步；缺开关或 API Key 时仍禁用。
- 来源状态和同步历史读取失败时保留卡片并标记可能过期，重新确认前禁止启动新同步。
- 任务轮询同一时间只有一个请求；停止轮询后旧响应不能更新状态。
- 同步完成时间同时显示精确时间和本地化相对表示，超过 30 天才提示重新同步。
- 导入审核的来源计数是当前标签下的全局数量，不能退化为已加载页面的局部计数。
- 游戏在接受前必须完成重复检查；未检查或检查失败时禁止安全批量接受。
- 已读取到重复候选时，单条或批量接受都必须二次确认。
- 接受或忽略后的刷新必须绑定当前标签、来源和分页视图。

## 数据健康与重复候选

- 数据健康页面只读展示问题，不在读取时自动修改记录。
- 摘要、字段问题和重复候选错误相互独立；任一读取失败都不能显示健康空状态。
- 字段修复只填充用户选择的空字段；影视使用 TMDB，游戏自动修复只支持 RAWG 封面。
- 重复候选先按共同外部 ID；无共同 ID 时影视按规范化标题和年份，游戏按规范化标题及平台
  关系。标题规范化必须保留 `&` 等连接符语义。
- `scope=all|pending` 在服务端完整过滤后分页，并返回对应范围的候选计数。
- 逐组核对一次只显示一组，区分本次已完成数量和剩余位置；前后切换不代表批量处理。
- 恰好只有一条 `ACCEPTED` 游戏记录时才能建议其为主记录；没有或存在多条时不猜测。
- 合并预览重新读取当前候选，逐条列出平台、公开 ID、源记录、指标和迁移去向。
- 任一候选已正式入库时，合并结果必须保持正式入库；个人字段冲突会阻断最终合并。

## 搜索、雷达与工具

- 搜索结果绑定关键词、Provider 和页码；输入新关键词后立即移除旧结果。
- 展开详情独立采用最新请求获胜；旧条目详情不能显示到新条目下。
- 同一搜索组件只允许一个添加请求；成功后立即标记已入库。
- 重新刮削在选中候选后锁定详情读取和写入，完成前不能并发选择另一候选。
- 雷达和热门的分类、平台、分页请求采用最新请求获胜；翻页失败保留当前页。
- 加入资料库按条目防止重复提交，失败只反馈该条操作，不污染列表读取错误。
- 工具页搜索失败保留明确错误和原关键词重试；分类转换成功后移除失效的源记录结果。
- 资料库快照必须同时校验正文清单、响应头和重新计算的 SHA-256 后才保存。
- 选择新快照后立即清除旧预览；旧文件请求成功或失败不得覆盖当前选择。
- 恢复预览必须校验 v2 格式、导出时间、计数清单、记录 ID、平台身份和 SHA-256，再读取
  现库生成差异；无效文件不能显示为健康空状态。
- 恢复预览只显示快照独有、内容不同、完全相同、身份冲突和现库独有，不提供写入入口；
  “现库独有”不等于待删除。

## 操作日志

- 数据变更筛选覆盖 `CREATE|UPDATE|DELETE|UNDO|MERGE`，任务筛选覆盖全部任务生命周期。
- 全局与记录级日志绑定当前筛选或实体；分页失败保留已有记录与游标。
- 撤销失败显示具体原因，不显示读取重试入口。
- 豆瓣影视 CREATE 返回 `undoable=false`，前端不得展示撤销按钮。
