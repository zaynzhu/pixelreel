# 工具页面 - 修改记录类型 设计文档

## 概述

创建"工具"页面（`/tools`），提供"修改记录类型"功能，支持电影和电视剧之间的类型转换。

## 背景

用户在导入数据时，有时会将电视剧错误地标记为电影（或反之）。需要一个工具来修正记录类型，而不需要手动操作数据库。

## 设计

### 页面路由

- 路径：`/tools`
- 导航位置：在"系统设置"之前
- i18n key：`nav.tools`（TOOLS / 工具）

### 搜索逻辑

- 搜索范围：movie 表和 tv_show 表
- 搜索字段：title、doubanTitle、tmdbTitle
- 返回结果：id、category、title、posterUrl、sourceLabel、doubanDate
- 排序：按 doubanDate 降序（最新标记的在前）

### 转换逻辑

1. 用户点击"转换为电视剧"或"转换为电影"
2. 系统自动备份原始数据到 `temp/convert_{id}_{timestamp}.json`
3. 从源表读取完整记录
4. 在目标表创建新记录（保留所有字段）
5. 删除源表记录
6. 显示成功消息，包含新记录 ID

### 字段映射

movie 表和 tv_show 表的字段几乎相同，只有以下差异：

| movie 字段 | tv_show 字段 | 说明 |
|------------|--------------|------|
| releaseDate | firstAirDate | 日期字段名不同 |

转换时需要：
- movie → tv_show：将 `releaseDate` 映射到 `firstAirDate`
- tv_show → movie：将 `firstAirDate` 映射到 `releaseDate`

### 后端 API

```
POST /api/tools/convert-category
Body: { id: number, from: "movie"|"tv_show", to: "movie"|"tv_show" }
Response: { success: boolean, newId: number, backupPath: string }
```

### 数据备份

- 备份路径：`express-backend/temp/convert_{id}_{timestamp}.json`
- 备份内容：完整记录数据（JSON 格式）
- 备份时机：转换操作前
- 备份删除：转换成功后自动删除
